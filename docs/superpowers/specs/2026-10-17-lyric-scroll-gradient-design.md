# 歌词滚动渐变模式设计

## 目标

在歌切制作台现有的歌词时间线展示之外，新增“滚动渐变”展示方式。用户可在编辑器中切换，播放预览和最终 MP4 导出采用同一种效果。

## 交互与效果

- 展示设置包含“时间线”和“滚动渐变”两种模式，默认保持现有时间线模式。
- 滚动模式按歌词时间顺序纵向排列；播放进度推进时，歌词连续向上移动，当前句靠近歌词区域中央。
- 歌词区域上下边缘使用透明渐变淡出，当前句和相邻句保持清晰可读。
- 暂停或拖动播放进度时，效果停留在对应时间；首尾歌词保持在区域内，不循环。
- 模式设置写入项目 JSON 和本地草稿，重新打开项目后保留。

## 实现范围

- 浏览器 Canvas 预览与本机 Pillow/FFmpeg 导出渲染同步支持两种模式。
- 编辑器增加清晰的模式切换控件；不改变歌词导入、编辑、排序和时间戳格式。
- 导出仍由现有离线合成流程生成，不改变分辨率、编码和取消方式。

## 验收标准

- 默认项目的预览与导出仍显示现有时间线布局。
- 切换到滚动渐变后，播放预览随时间连续上移，歌词上下缘渐隐。
- 导出的 MP4 在相同时间点显示同样的滚动位置与渐隐效果。
- 保存并重新打开项目后，所选模式仍保留；无歌词时页面正常显示。
