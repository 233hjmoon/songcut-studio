# 双模式视频导出设计

## 目标

让用户可以按项目和电脑性能选择实时录制或离线直接合成；两种方式都下载 MP4，并保留现有成片画面和音频。

## 用户界面

- 在导出按钮旁提供「导出方式」选择：「直接合成」和「实时录制」。默认选中直接合成，避免改变已有项目的工作方式。
- 按钮文案和进度提示反映所选方式。实时录制提示需要从头播放到结尾；处理中允许取消。
- 导出期间禁用会改变成片的编辑、素材替换和播放定位操作，完成或取消后恢复。

## 实时录制流程

1. 校验浏览器支持 `canvas.captureStream`、`MediaRecorder` 及输入媒体音轨捕获。
2. 将素材定位到 0 秒，准备 1920×1080 画布流（30 fps）并从当前音视频元素取得音轨；只将音轨并入画布流，避免视频画面重复。
3. 从头播放素材并录制画布与原音频。现有动画循环依播放时间绘制歌词；记录期间忽略外部播放控件和时间轴跳转，素材结束或录制失败时停止录制。
4. 浏览器每秒将 WebM 片段追加到本机临时文件，避免长歌的录制数据一直占用内存；录制结束后使用 FFmpeg 转码为 MP4。显示录制和转换阶段状态，取消时停止播放、释放媒体轨道并清理临时文件。
5. 成功后下载 MP4。源文件仍只在本机处理。

## 直接合成

保留现有本机 FFmpeg 渲染与合成流程及其进度、取消、MP4 下载行为。两种模式使用相同项目画面设置。

## 错误处理

- 缺少浏览器录制能力或媒体音轨捕获能力时，在开始前说明原因，不自动切换模式。
- 浏览器录制中断、转换失败或用户取消时，恢复编辑状态并清理流、录制片段及服务端临时素材。
- 音频输入仅录制音轨；视频输入录制其音轨（若有）以及当前画布中的视频画面。没有音轨的视频生成无声 MP4。

## 验证

- 测试录制流轨道组合、导出状态及取消/清理逻辑。
- 测试本机 WebM 到 MP4 的服务端转换，检查 MP4 可读、时长、画面帧率和音频轨。
- 手动验证音频素材和带音轨/无音轨视频素材在两种导出方式下的歌词同步与取消行为。
