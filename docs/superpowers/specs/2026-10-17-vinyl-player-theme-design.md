# 黑胶歌词主题设计

日期：2026-10-17

## 目标

在歌切制作台增加一套黑胶唱片风格的播放主题。用户确认的布局草稿保存在 `outputs/songcut-studio/.superpowers/brainstorm/2026-10-17-controls-outside-canvas/content/layout-v1.html`。新主题采用左侧黑胶唱片与唱臂、右侧歌曲信息和逐句歌词、底部进度与上一首／播放暂停／下一首控制。

保留已有三套主题和现有“流光播放器”主题。新主题的背景来源设置放在工作台内容编辑区，不放进成片画布。导出的 PNG 和视频只包含播放器内容，不显示背景来源按钮、图片导入按钮或其他工作台控件。

## 方案

新增独立的第四套主题“黑胶歌词”，避免覆盖已经存在的“流光播放器”。主题切换仍应用到整套制作台；新增背景设置作为工作台中的编辑控件，实际背景绘入 16:9 画布，因此预览、PNG 和三种视频导出方式保持一致。

不把工作台 DOM 作为成片层，也不通过导出后裁切移除设置控件。浏览器预览和导出继续共用画布绘制结果，离线 30 帧、原视频直合 60 帧与实时录制分别按各自既有画布／渲染器入口绘制同一布局。

## 背景设置与取色

- 新主题工作台提供“视频取色渐变”和“自定义背景图片”两种来源。
- 选择“视频取色渐变”时，从导入视频时长中点的可解码画面抽取主色，生成低对比度的纯色多段渐变；取色时暂时定位视频并在完成后恢复原播放位置。渐变保留为静态色板，不显示或模糊铺满原视频画面。更换视频后更新色板。
- 没有可用视频时使用主题自带的深蓝渐变。取色模式在未导入视频时仍可见并说明会使用默认渐变。
- 选择“自定义背景图片”时，可在工作台上传图片作为成片背景；画布按填满 16:9 的方式裁切显示。切换回视频取色时保留已上传图片，方便往返选择。
- 设置与图片数据随本地草稿和 JSON 项目保存；重开项目后恢复所选来源及对应背景。
- 背景图像和颜色色板是项目素材，不是工作台控件；所有画布导出均包含所选背景。

## 画面与交互

- 左侧展示缩小后的黑胶唱片、唱片标签和唱臂；使用原创抽象标签，不带平台标识。
- 右侧展示歌曲标题、歌手／主播、歌词列表。当前句清晰高亮，其余歌词减淡；沿用现有时间线和滚动渐变两种歌词模式。
- 底部只保留播放进度、上一首、播放／暂停和下一首。没有红心、歌单或背景设置图标。
- 背景来源、取色状态、图片导入和移除操作只显示在制作台编辑区。它们不进入播放器画布，也不进入任何导出文件。
- 主题切换后项目草稿、项目 JSON、PNG 预览和各视频导出均使用相同的选中背景与布局。

## 项目数据

新增主题标识 `vinyl-player`。项目状态保存背景来源（`video-color` 或 `custom-image`）、视频取色色板，以及自定义背景图数据。旧项目没有这些字段时采用视频取色来源和内置深蓝渐变，原三套主题的默认值与渲染保持不变。

## 错误与回退

- 视频尚未解码或无法取色时使用上次有效色板；若没有则使用内置深蓝渐变，并在工作台给出提示。
- 图片导入失败时保留之前选定的有效背景，并显示可理解的错误。
- 自定义图片模式没有有效图片时回退到当前有效的取色色板或默认渐变，避免空白背景。
- 取色与图片加载不得阻塞音频播放、歌词编辑或视频导出取消操作。

## 验收标准

1. 主题选择器新增“黑胶歌词”；原有主题和旧项目显示不变。
2. 新主题布局与已存档草稿一致：左侧黑胶、右侧逐句歌词、底部仅进度和三个播放控制。
3. 工作台可在视频取色渐变和自定义背景图片间切换；更换视频、保存草稿、刷新页面、JSON 导出再导入后状态可恢复。
4. 视频取色只产生纯颜色渐变，不把视频帧、光斑或景物铺成背景；无视频时显示内置深蓝渐变。
5. PNG、30 帧合成、60 帧视频直合和实时录制都包含选定背景及新主题布局，且不包含任何背景设置控件。
6. 三种现有主题与“流光播放器”的预览、PNG 和视频导出保持原样。
7. 图片加载失败、视频无可用帧和导出取消时，页面保持可继续操作并给出状态提示。

## 验证重点

覆盖视频取色、自定义图片和默认渐变三种背景状态；在浏览器预览、PNG、30 帧、60 帧和实时录制中核对画布边缘与底部控件；检查本地草稿和 JSON 往返；确认旧项目仍选择原主题并保持原视觉。
