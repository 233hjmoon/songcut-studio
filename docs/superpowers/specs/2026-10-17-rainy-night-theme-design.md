# 雨后便利店主题设计

## 目标

为歌切制作台增加第二套可切换主题。用户可在现有暖纸唱片主题与“雨后便利店”主题之间切换；切换会同时影响制作台界面、浏览器中的 16:9 成片预览，以及最终 MP4 的离线合成画面。

## 视觉方向

以参考图提取色调，不把参考图直接铺成固定背景。雨后便利店主题使用深海军蓝与夜空蓝作为主底色，冷白和青蓝作为灯光及强调色，少量雾紫表现远岸灯影。保留现有唱片、封面和歌词排版结构，改为深色半透明信息面板与细蓝光网格，让歌词在复杂背景氛围上仍有足够对比度。上传封面继续显示在唱片封面区域。

## 交互与状态

- 在制作台顶部提供清晰的主题切换控件，包含“暖纸唱片”和“雨后便利店”。
- 当前选择写入本地草稿和项目 JSON；旧项目缺少主题字段时采用暖纸唱片主题。
- 导入旧 JSON 或新 JSON 后，界面控件与成片画布立即同步到项目所选主题。

## 实现范围

- 用统一的主题色值分别驱动页面 CSS、Canvas 预览和 Pillow 视频帧渲染，确保主题在整个制作台与导出画面一致。
- 保持现有布局、歌词时间线／滚动渐变模式、封面和视频变换、音视频导入与 FFmpeg 直接合成行为。
- 不把原始参考图作为成片背景素材；主题通过配色、半透明面板、细网格和冷光细节建立氛围。

## 验收标准

- 默认与旧 JSON 均保持暖纸唱片外观。
- 切换到雨后便利店后，制作台控件、画布预览、歌词高亮、页眉页脚和背景一并变为夜蓝冷光色系。
- 预览与 MP4 导出使用同一套主题，歌词在两种主题及两种歌词表现模式下均保持清晰。
- 保存或导入项目后，主题选择正确恢复；主题切换不会影响已有歌词、素材和画面变换。
